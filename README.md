# 1% Better - Habit Tracker

A simple habit tracker built with HTML, CSS and JavaScript.

## Features
- Add habits with a time and days of the week
- Tick habits off each day
- Daily progress bar and 7-day improvement chart
- Streak counter for days when all habits are completed
- "1% better every day" growth score

## How to run
Open `index.html` in a browser or use VS Code Live Server.
